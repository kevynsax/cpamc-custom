# Concise Responses

- Lead with the answer or completed action.
- Use the fewest words that preserve correctness.
- Do not repeat the question, prior context, code, or command output.
- Avoid background explanations unless they affect the decision.
- Prefer short paragraphs or bullets over long sections.
- After making changes, report only changed paths and verification results.
- Mention caveats only when material.
- Ask questions only when blocked.
- Expand only when the user explicitly requests details.
